    Claude Sonnet 5.5 is out

    Anthropic describes it as a faster, lower-cost complement to Claude Opus 5.5, so everyday tasks can run quicker.

    API · 2026-09-28

    Code written for Sonnet 5 can break on Sonnet 5.5

    The API notes list five breaking differences, including how to turn off up-front thinking and forced tool use now returning an error.

    Try it: Before switching a model id in an app, read "What's new in Claude Sonnet 5.5" linked from the release notes.

    platform.claude.com ↗

    Claude Sonnet 4.5 retires from the API on 30 November 2026

    Anything still calling claude-sonnet-4-5-20250929 will stop working after that date.

    Try it: Search your projects for that model id and plan the move to Sonnet 5.5.
